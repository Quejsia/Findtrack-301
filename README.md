# FindTrack

**A community lost-and-found web app for the Philippines.** FindTrack helps people recover lost belongings through trusted community reporting and verified recovery workflows, built on the spirit of *bayanihan*.

Report something you lost or found, get matched with likely candidates, prove ownership, and arrange a safe hand-off, all in one place.

## Features

- Report **lost** or **found** items with details and a photo.
- AI-assisted photo analysis and **smart match suggestions** to connect lost and found reports.
- Search and filter by keyword, status, location, date and category.
- **Ownership claims** with a verification question, reviewed by the finder before contact details are shared.
- Direct chat between the two parties.
- Points, levels and community analytics.
- Email verification, guest browsing and profile settings.
- Available in English, Spanish, French, Filipino and Chinese.

## Built with

React, TypeScript, Vite, Tailwind CSS, Firebase and Cloudinary, deployed on Vercel.

## Getting started

**Prerequisites:** Node.js 20 or later.

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and fill in your own values. Never commit `.env`.
3. Start the dev server:
   ```bash
   npm run dev
   ```
   The app runs at <http://localhost:3000>.

Other commands: `npm run build`, `npm start`, `npm run lint`.
